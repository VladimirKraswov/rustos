  /system/bin/ipc-sender.elf   VFS capability sender

  /system/lib/vfs-1.dll
  /system/lib/ui-1.dll
  /system/bin/fs
  /system/bin/editor
  /system/bin/rustc

capability IPC; driver code is never copied into every application.
